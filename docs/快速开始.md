# 🚀 快速开始指南 (Quick Start Guide)

本指南介绍如何下载、运行和构建摸鱼侠。

---

## 方式 1：直接下载桌面版安装包 (推荐，开箱即用)

前往 [摸鱼侠发布页](https://github.com/zhangga/ShortDramaPlayer/releases/latest) 下载 Windows x64 便携版。完整解压 `ShortDramaPlayer-win-x64.zip` 后运行 `摸鱼侠.exe`，旧版的程序名为 `ShortDramaPlayer.exe`。

macOS Apple Silicon 预览版可按 [README](../README.md#从源码构建) 构建。打开 DMG 后将 `摸鱼侠.app` 拖入「应用程序」，ZIP 版解压后即可打开应用。

---

## 方式 2：本地运行原生桌面客户端 (开发/调试)

```bash
# 1. 克隆仓库并安装依赖
git clone https://github.com/zhangga/ShortDramaPlayer.git
cd ShortDramaPlayer
npm install

# 2. 启动原生桌面应用 (Electron 独立原生窗口，自动适配 Windows / macOS)
npm run app
```

---

## 方式 3：直接构建各平台原生安装包

项目支持在本地一键打包各平台二进制发行包：

```bash
# 构建 Windows 安装包 (生成 Setup .exe 及便携 zip)
npm run build:win

# 构建 macOS 双架构安装包 (.dmg 及 .zip)
npm run build:mac

# 一键全平台构建 (macOS + Windows)
npm run build:all
```
构建产物均保存在 `dist-electron/` 目录中。

---

## 方式 4：纯后台服务 / Web 浏览器模式

如果希望在家庭服务器、NAS 或局域网内运行，可通过 Web 模式启动：

* **启动服务**：`npm start`，随后在浏览器访问 `http://127.0.0.1:8899`
* **一键启动脚本**：
  * **macOS / Linux**：终端执行 `./start.sh`（自动检测依赖并唤起本地服务）
  * **Windows**：双击运行 `start.bat`


---

## 自动化测试

```bash
# 运行本地回归测试和真实接口端到端测试
npm test

# 仅运行不访问上游网络的回归测试
npm run test:unit

# 单独运行真实接口端到端测试
npm run test:e2e
```

端到端测试使用独立临时目录，不修改个人观看记录或收藏。真实接口测试需要网络可达，覆盖目录、搜索、分集解析、视频下载与解密、HEAD/Range 响应及用户数据持久化。

常规 CI 和安装包构建仅运行本地回归测试。`Live API Verification` 工作流单独在 macOS、Windows 和 Linux 运行真实接口检查；第三方服务不可用时，该工作流会明确失败，但不会中断安装包构建。

正式安装包仅在推送 `v*` 版本标签或手动触发 `Build & Release Native Apps` 时生成和发布。普通主分支提交继续运行验证，不再逐次发布正式版本。
