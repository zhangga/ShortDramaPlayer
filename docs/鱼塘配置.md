# 鱼塘配置

桌面版从右上角「菜单与帮助 → 鱼塘」进入。个人计分保存在播放器本地。填昵称加入总榜后，才同步加入当天及之后的每日鱼数。退出榜单后立即停止上报，已有成绩会在联网时从榜单撤下。

## 创建并配置 Supabase 项目

1. 在 [Supabase Dashboard](https://supabase.com/dashboard) 创建一个项目。
2. 打开项目的 **Authentication**，在登录方式设置里启用 **Allow anonymous sign-ins**，并允许新用户注册。播放器会在用户加入榜单时创建匿名身份。[匿名登录设置](https://supabase.com/docs/guides/auth/auth-anonymous)
3. 打开 **SQL Editor**，新建查询，粘贴并运行 [fishing.sql](../supabase/fishing.sql) 的全部内容。它会创建成绩表和提交、查询、退出三个接口。日榜和周榜使用北京时间，周一开始新的一周。
4. 从 **Connect** 或 **Settings → API Keys** 复制 **Project URL** 和 **Publishable key**，例如 `https://<project-ref>.supabase.co` 和 `sb_publishable_…`。把它们填到 [fishing-config.json](../src/server/fishing-config.json) 的 `url` 和 `publishableKey`。发布配置只使用 Publishable key，数据库密码、Secret key 和 `service_role` key 留在项目管理端。[API Keys 说明](https://supabase.com/docs/guides/getting-started/api-keys)
5. 重启播放器。准备公开发布时，将填好的配置随 Windows 和 macOS 安装包一起打包，两个平台使用同一个项目。启动后打开「鱼塘」，用测试昵称验证加入、日榜、周榜和退出。

也可以用环境变量临时配置当前构建。PowerShell 示例：

```powershell
$env:FISHING_SUPABASE_URL = 'https://<project-ref>.supabase.co'
$env:FISHING_SUPABASE_PUBLISHABLE_KEY = 'sb_publishable_...'
npm run app
```

Windows 便携版可从同一个 PowerShell 窗口启动 `摸鱼侠.exe`。测试不同项目时请使用各自的播放器数据目录，以保留各项目独立的匿名登录状态。无有效配置时，个人统计和结算仍然可用。

## 验证同步

加入后，用大窗播放至少 3 分钟，再刷新今日榜。正常运行时大约每 30 秒重试同步，退出会先保存本地成绩，联网后的下次启动也会补传。榜单展示昵称、鱼数和名次。播放内容、观看时长和结算设置留在本机。
